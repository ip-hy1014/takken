# 宅建学習

自分用の学習ページです。スマホでは https://ip-hy1014.github.io/takken/ を開き、パスワードを入力します。進捗は、開いたブラウザの中だけに保存されます。

2026年10月18日の宅建試験に向けて、短い問題を繰り返します。忘却曲線に沿って、忘れかける前に復習が出ます。

## できること

- 125問。配点の大きい宅建業法から出します
- 正解しても10分後にもう一度出ます。不正解はすぐ再出題し、10分後にも出ます
- その後は1日、3日、7日と間隔を空けます
- 連続正解、経験値、連続日数、今日の課題、予測得点、試験までの日数
- 今日の課題を3つ終えると、経験値が2倍になります
- キーボードの1〜4でも選べます。Enterで次へ進みます

合格を保証するものではありません。試験前に [公式](https://www.retio.or.jp/exam/exam_detail/) と最新法令を確認してください。
